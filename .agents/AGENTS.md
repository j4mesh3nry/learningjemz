# Project Rules

- **Git Workflow**: Always work on the `dev` branch or module feature branches (`feature/*`). After completing edits and verifying changes, commit and push immediately to `origin/dev`.
- **Documentation Requirement**: Whenever merging features or releasing to `main`, always update `GAME_DOCUMENTATION.md` with the latest feature status, mechanics, and design changes.
- **Iconography Rule**: Strictly NO emojis in UI or code for icons/graphics. Always use Lucide React icons or custom SVG icons. Custom icons must follow the flat, stroke-based Lucide grammar (24x24 viewBox, `stroke="currentColor"`, no fill, `strokeLinecap/Linejoin: round`). NO cartoon, cutesy, or emoji-style icon artwork.
- **Design Aesthetics Rule**: Strictly avoid glassmorphism (`backdrop-filter`), and ANY translucent or semi-transparent surface (no `rgba()`/`hsla()`/`opacity` backgrounds on panels, buttons, cards, overlays, stat tiles, or borders — solid hex fills only). The ONE allowed exception is the full-screen modal backdrop scrim (e.g. `rgba(0,0,0,0.65)`) used to dim the page behind modals.
- **No Glow Rule**: No neon/glow effects of any kind: no `box-shadow` with a blur radius (`box-shadow: 0 0 8px ...`), no `text-shadow` glows, no radial-gradient auras, no gradient text (`background-clip: text`). Only tactile offset 3D shadows are allowed (e.g. `box-shadow: 0 4px 0 <solid color>`).
- **Theme Connection Rule**: All module screens and modals must hook into the global design tokens in `src/index.css` (`--bg-space`, `--bg-geo`, `--bg-chess`, `--bg-reading`, `--color-*`, `--font-heading`). Match the established module palette (e.g. the `theme-space` variant in `victory.css`) so screens never look out of place.
- **No Visible Scrollbars Rule**: The UI must never show scrollbars — neither on the page nor inside scrollable containers (tabs, panels, the reader, game history, etc.). Scrolling must still work. Enforced globally in `src/index.css` (`scrollbar-width: none` + `-ms-overflow-style: none` + `*::-webkit-scrollbar { display: none; }`); never re-enable a visible scrollbar on any element.
